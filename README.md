# ☁️ Desafios do Bootcamp Microsoft Azure Cloud Native

Este repositório contém os **desafios práticos** realizados durante o bootcamp **Microsoft Azure Cloud Native**, promovido pela DIO. Aqui estão descritos os projetos desenvolvidos para reforçar habilidades com a plataforma Azure, utilizando recursos como AKS, Functions, API Management, App Service e GitHub Copilot.

## 📌 Desafios de Projeto

### 1. Armazenando dados de um E-Commerce na Cloud
Neste desafio, desenvolvemos a estrutura de armazenamento em nuvem para um sistema de e-commerce, utilizando os serviços do Azure para garantir escalabilidade, segurança e alta disponibilidade.

---

### 2. Criando um Blog com Container Apps 
Construção de uma aplicação de blog utilizando Azure Container Apps. O desafio foca na criação, publicação e gerenciamento de uma aplicação containerizada na nuvem.

---

### 3. API de Pagamentos Segura com Azure API Management  
Neste projeto, configuramos e publicamos uma API de pagamentos com foco em segurança e gerenciamento de acesso, utilizando o Azure API Management.

---

### 4. Criando um Serviço Autenticador de Boletos  
Desenvolvimento de uma aplicação serverless com Azure Functions para autenticar boletos bancários, aplicando princípios de computação sob demanda e arquitetura reativa.

---

### 5. Instalação e Configuração do GitHub Copilot com o VS Code  
Desafio focado na configuração da ferramenta GitHub Copilot com o Visual Studio Code, integrando IA no fluxo de desenvolvimento para sugestões de código inteligentes.

---

### 6. Construção de uma Aplicação de Aluguel de Carros totalmente Cloud-Native  
Desenvolvimento completo de uma aplicação de aluguel de carros utilizando os principais recursos cloud-native da Azure, desde a infraestrutura até a publicação e escalabilidade.
