## 📝 Introdução

O objetivo deste projeto é desenvolver um serviço web para autenticação e validação de códigos de barras de boletos bancários. A aplicação permite aos usuários inserir códigos de barras e verifica sua validade, extraindo informações como valor e data de vencimento.

Este projeto é parte do desafio proposto pela DIO para aplicar os conceitos aprendidos sobre desenvolvimento web, validação de dados e boas práticas de programação, criando uma solução prática que poderia ser implementada em um cenário real de processamento de pagamentos.

### Criando o módulo de validação

Criamos o arquivo `validador.py` com as funções necessárias para validar e extrair informações dos códigos de barras:

```python
"""
Módulo para validação de códigos de barras de boletos bancários.
"""

def validar_codigo_barras(codigo):
    """
    Valida um código de barras de boleto bancário.
    
    Args:
        codigo (str): O código de barras a ser validado.
        
    Returns:
        dict: Um dicionário contendo o resultado da validação e informações extraídas.
    """
    # Remover espaços e caracteres não numéricos
    codigo = ''.join(c for c in codigo if c.isdigit())
    
    # Validações básicas
    if not codigo:
        return {
            "valido": False,
            "mensagem": "Código de barras vazio ou inválido."
        }
    
    # Validação de comprimento para boletos bancários (44 dígitos)
    if len(codigo) != 44:
        return {
            "valido": False,
            "mensagem": f"Código de barras deve ter 44 dígitos. Encontrado: {len(codigo)}"
        }
    
    # Simulação de validação do dígito verificador
    # Em um cenário real, implementaríamos o algoritmo específico de validação
    digito_verificador = int(codigo[4])
    
    # Extrair informações do boleto (simulado)
    valor = extrair_valor(codigo)
    data_vencimento = extrair_data_vencimento(codigo)
    
    return {
        "valido": True,
        "mensagem": "Código de barras válido.",
        "valor": valor,
        "data_vencimento": data_vencimento
    }

def extrair_valor(codigo):
    """
    Extrai o valor do boleto a partir do código de barras.
    
    Args:
        codigo (str): O código de barras.
        
    Returns:
        str: O valor formatado do boleto.
    """
    # Em um cenário real, implementaríamos a lógica específica
    # Simulação: os dígitos 9-19 representam o valor (com 2 casas decimais)
    valor_str = codigo[9:19]
    valor_int = int(valor_str)
    valor_formatado = f"R$ {valor_int/100:.2f}"
    
    return valor_formatado

def extrair_data_vencimento(codigo):

    Extrai a data de vencimento do boleto a partir do código de barras.

        str: A data de vencimento formatada.
    """
    # Em um cenário real, implementaríamos a lógica específica
    # Simulação: os dígitos 5-9 representam o fator de vencimento

    # Simulação simples para demonstração

    return "15/06/2025"
```

2. **Limpeza do código**: Removemos espaços e caracteres não numéricos para facilitar a validação.

## 🖥️ Passo 3: Criando camada de UI

Nesta etapa, desenvolvemos a interface do usuário para interação com o serviço de validação de boletos.

### Criando o arquivo principal da aplicação

Criamos o arquivo `main.py` que serve como ponto de entrada da aplicação:

```python
# Arquivo principal da aplicação Flask

from flask import Flask, render_template, request, flash
from validador import validar_codigo_barras

app = Flask(__name__)
app.secret_key = 'autenticador_boletos_secret_key'

@app.route('/')
def index():
    return render_template('index.html')

@app.route('/validar', methods=['POST'])
def validar_boleto():
    codigo_barras = request.form.get('codigo_barras', '')
    
    # Validações na camada de UI
    if not codigo_barras:
        flash('Por favor, insira um código de barras.', 'error')
        return render_template('index.html')
    
    # Remover caracteres não numéricos para facilitar a entrada do usuário
    codigo_limpo = ''.join(c for c in codigo_barras if c.isdigit())
    
    # Validar o código de barras
    resultado = validar_codigo_barras(codigo_limpo)
    
    return render_template(
        'resultado.html', 
        mensagem=resultado['mensagem'],
        valido=resultado['valido'],
        valor=resultado.get('valor', ''),
        data_vencimento=resultado.get('data_vencimento', '')
    )

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0')
```

## 🔍 Passo 4: Validações na camada de UI

Nesta etapa, implementamos validações na camada de interface do usuário para melhorar a experiência e prevenir erros.

### Validações implementadas:

1. **Verificação de campo vazio**: Utilizamos o atributo `required` no HTML e também uma verificação no servidor para garantir que o usuário insira um código de barras.

2. **Limpeza de caracteres não numéricos**: Implementamos uma função para remover espaços, traços e outros caracteres não numéricos do código de barras, facilitando a entrada do usuário.

3. **Feedback visual**: Utilizamos cores diferentes para indicar se o código é válido (verde) ou inválido (vermelho).

4. **Mensagens de erro claras**: Implementamos mensagens de erro específicas para diferentes tipos de problemas (campo vazio, comprimento incorreto, etc.).

5. **Instruções para o usuário**: Adicionamos instruções claras na página inicial para orientar o usuário sobre como utilizar o serviço.

